# Теория графов и комбинаторная оптимизация

> Материал для трека «МАИ», подготовленный по программе вступительного экзамена и конспекту mai.md.

### 1. Основные понятия теории графов

* **Задание графа:** Граф $G = (V, E)$, где $V$ — множество вершин, $E$ — множество ребер/дуг.
* *Матрица смежности:* $A_{n \times n}$, где $a_{ij} = 1$, если есть ребро $(v_i, v_j)$, иначе $0$. Память $O(\vert{}V\vert{}^2)$.
* *Матрица инцидентности:* $B_{\vert{}V\vert{} \times \vert{}E\vert{}}$, где $b_{ik} = 1$, если вершина $v_i$ инцидентна ребру $e_k$.
* *Списки смежности:* Массив списков, где для каждой вершины хранится список ее соседей. Память $O(\vert{}V\vert{} + \vert{}E\vert{})$.


* **Изоморфизм графов:** Графы $G_1=(V_1, E_1)$ и $G_2=(V_2, E_2)$ изоморфны, если существует биекция $f: V_1 \to V_2$, сохраняющая смежность: $(u, v) \in E_1 \iff (f(u), f(v)) \in E_2$.
* **Связность:**
* *Неориентированный граф:* **Связный**, если между любыми двумя вершинами есть путь.
* *Ориентированный граф (Оргграф):*
* **Сильно связный:** Между любыми двумя вершинами есть ориентированный путь в обе стороны.
* **Слабо связный:** Граф становится связным, если заменить все дуги на неориентированные ребра.




* **Конденсация оргграфа:** Граф $G^*$, вершинами которого являются компоненты сильной связности графа $G$, а дуга между компонентами $C_i$ и $C_j$ существует, если в $G$ есть хотя бы одна дуга из вершины $C_i$ в $C_j$. *Граф конденсации всегда является бесконтурным (DAG).*

### 2. Задачи на графах

* **Достижимость:** Проверка существования пути между вершинами $u$ и $v$. Решается обходом в глубину (DFS) или ширину (BFS) за время $O(\vert{}V\vert{} + \vert{}E\vert{})$, либо транзитивным замыканием (Алгоритм Уоршелла $O(\vert{}V\vert{}^3)$).
* **Доминирующее множество (Dominating Set):** Подмножество вершин $D \subseteq V$, такое что любая вершина не из $D$ смежна хотя бы одной вершине из $D$. (Задача поиска наименьшего доминирующего множества является NP-трудной).

---

### 3. Кратчайшие пути: Алгоритм Дейкстры

* **Назначение:** Нахождение кратчайших путей от одной фиксированной вершины до всех остальных в взвешенном графе с **неотрицательными весами ребер** ($w(e) \ge 0$).
* **Идея алгоритма (Жадный подход):**
1. Инициализация: $d[v] = \infty$, $d[start] = 0$. Все вершины не помечены.
2. На каждом шаге выбирается непомеченная вершина $u$ с минимальным значением $d[u]$.
3. Помечаем $u$ как посещенную.
4. Выполняется **релаксация** всех исходящих ребер $(u, v)$: $d[v] = \min(d[v], d[u] + w(u, v))$.
5. Повторяем, пока есть непомеченные вершины.


* **Сложность:** $O(\vert{}V\vert{}^2)$ при простом массиве; $O((\vert{}V\vert{} + \vert{}E\vert{}) \log \vert{}V\vert{})$ при использовании двоичной кучи (Binary Heap).

### 4. Гамильтоновы и Эйлеровы пути

| Характеристика | Эйлеров путь / Цикл | Гамильтонов путь / Цикл |
| --- | --- | --- |
| **Определение** | Проходит через **каждое ребро** графа ровно по одному разу. | Проходит через **каждую вершину** графа ровно по одному разу. |
| **Критерий существования** | **Критерий Эйлера:** Связный неориентированный граф содержит эйлеров цикл $\iff$ **степени всех вершин четны**. Содержит эйлеров путь $\iff$ ровно 2 вершины имеют нечетную степень. | **Точного критерия нет (NP-полная задача).** Достаточные условия: *Теорема Дирака* ($\deg(v) \ge n/2$), *Теорема Оре* ($\deg(u)+\deg(v) \ge n$). |
| **Сложность поиска** | Полиномиальная ($O(\vert{}E\vert{})$ — Алгоритм Флёри или алгоритм Эйлера на основе DFS). | NP-полная задача (в общем случае доступен только перебор / NP-hard). |

### 5. Задача коммивояжера (TSP) и Метод ветвей и границ

* **Формулировка задачи:** Дано $n$ городов и матрица расстояний между ними. Найти замкнутый маршрут минимальной длины, проходящий через каждый город ровно по одному разу (Гамильтонов цикл минимального веса). Задача NP-трудна.
* **Метод ветвей и границ (Branch and Bound):** Точный метод решения дискретных оптимизационных задач без полного перебора вариантов.
* **Алгоритм (на примере TSP / алгоритм Литтла):**
1. **Ветвление (Branching):** Множество всех возможных маршрутов рекурсивно разбивается на непересекающиеся подмножества (дерево поиска): включать ребро $(i, j)$ в маршрут или не включать.
2. **Оценивание (Bounding):** Для каждого подмножества решений рассчитывается **нижняя оценка (Lower Bound)** стоимости маршрута. Для этого матрица расстояний приводится (редуцируется) вычитанием минимумов по строкам и столбцам.
3. **Отсечение (Pruning):** Если нижняя оценка текущей ветви больше или равна длине уже найденного рекордного (лучшего) полного маршрута, эта ветвь полностью отсекается (не исследуется дальше).
