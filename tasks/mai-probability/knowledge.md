### 1. Основы комбинаторики

Пусть есть $n$ элементов, выбирается $k$ элементов:

| Вид комбинации | Порядок важен | Порядок НЕ важен |
| --- | --- | --- |
| **Без повторений** | **Размещения:** $A_n^k = \frac{n!}{(n-k)!}$<br>

<br>*(если $k=n$, **Перестановки:** $P_n = n!$)* | **Сочетания:** $C_n^k = \frac{n!}{k!(n-k)!}$ |
| **С повторениями** | **Размещения:** $\bar{A}_n^k = n^k$<br>

<br>**Перестановки:** $P_n(n_1..n_m) = \frac{n!}{n_1! n_2! \dots n_m!}$ | **Сочетания:** $\bar{C}_n^k = C_{n+k-1}^k$ |

### 2. Теория вероятностей

* **Теоремы сложения:**
* Для несовместных событий ($A \cap B = \emptyset$): $P(A \cup B) = P(A) + P(B)$.
* Для совместных событий: $P(A \cup B) = P(A) + P(B) - P(A \cap B)$.


* **Условная вероятность и умножение:**
* Условная вероятность: $P(A \mid B) = \frac{P(A \cap B)}{P(B)}$ (при $P(B) > 0$).
* Теорема умножения: $P(A \cap B) = P(B) \cdot P(A \mid B) = P(A) \cdot P(B \mid A)$.
* Для независимых событий: $P(A \cap B) = P(A) \cdot P(B)$.


* **Формула полной вероятности:** Если гипотезы $H_1, H_2, \dots, H_n$ образуют полную группу несовместных событий ($\sum P(H_i) = 1$), то для любого события $A$:

$$P(A) = \sum_{i=1}^{n} P(H_i) \cdot P(A \mid H_i)$$


* **Формула Байеса (переоценка вероятностей гипотез):**

$$P(H_k \mid A) = \frac{P(H_k) \cdot P(A \mid H_k)}{\sum_{i=1}^{n} P(H_i) \cdot P(A \mid H_i)}$$


* **Схема Бернулли:** $n$ независимых испытаний, в каждом вероятность успеха равна $p$, неуспеха $q = 1-p$. Вероятность получить ровно $k$ успехов:

$$P_n(k) = C_n^k \cdot p^k \cdot q^{n-k}$$

### 3. Случайные величины (СВ)

* **Дискретная СВ (ДСВ):** Принимает изолированные значения. Задается *рядом распределения* (таблица значений $x_i$ и вероятностей $p_i$, где $\sum p_i = 1$).
* **Непрерывная СВ (НСВ):** Принимает любые значения из некоторого интервала.
* **Функция распределения $F(x)$:** Вероятность того, что СВ $X$ принимает значение меньше $x$:

$$F(x) = P(X < x)$$


* Свойства: $0 \le F(x) \le 1$, $F(x)$ — неубывающая, $P(a \le X < b) = F(b) - F(a)$.


* **Плотность вероятности $f(x)$ (только для НСВ):** Производная функции распределения:

$$f(x) = F'(x), \quad F(x) = \int_{-\infty}^{x} f(t) \, dt, \quad \int_{-\infty}^{+\infty} f(x) \, dx = 1$$

### 4. Числовые характеристики СВ

* **Математическое ожидание $M[X]$ (среднее значение):**
* Для ДСВ: $M[X] = \sum x_i p_i$
* Для НСВ: $M[X] = \int_{-\infty}^{+\infty} x f(x) \, dx$
* *Свойства:* $M[C] = C$, $M[aX + b] = a M[X] + b$, $M[X + Y] = M[X] + M[Y]$.


* **Дисперсия $D[X]$ (мера рассеяния вокруг $M[X]$):**

$$D[X] = M[(X - M[X])^2] = M[X^2] - (M[X])^2$$


* Для ДСВ: $D[X] = \sum x_i^2 p_i - (M[X])^2$
* Для НСВ: $D[X] = \int_{-\infty}^{+\infty} x^2 f(x) \, dx - (M[X])^2$
* *Среднеквадратичное отклонение (СКО):* $\sigma_X = \sqrt{D[X]}$.


* **Моменты:**
* *Начальный момент $k$-го порядка:* $\alpha_k = M[X^k]$ (обратите внимание, $\alpha_1 = M[X]$).
* *Центральный момент $k$-го порядка:* $\mu_k = M[(X - M[X])^k]$ (обратите внимание, $\mu_2 = D[X]$).

### 5. Основные законы распределения

| Распределение | Вид СВ | $P(X=k)$ или $f(x)$ | $M[X]$ | $D[X]$ |
| --- | --- | --- | --- | --- |
| **Биномиальное** $\text{Bin}(n, p)$ | ДСВ | $P(X=k) = C_n^k p^k q^{n-k}$ | $n \cdot p$ | $n \cdot p \cdot q$ |
| **Геометрическое** $\text{Geom}(p)$ | ДСВ | $P(X=k) = q^{k-1} p$ (успех на $k$-м шаге) | $\frac{1}{p}$ | $\frac{q}{p^2}$ |
| **Пуассона** $\text{Pois}(\lambda)$ | ДСВ | $P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}$ | $\lambda$ | $\lambda$ |
| **Равномерное** $U(a, b)$ | НСВ | $f(x) = \frac{1}{b-a}, \quad x \in [a, b]$ | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ |
| **Нормальное** $N(\mu, \sigma^2)$ | НСВ | $f(x) = \frac{1}{\sigma \sqrt{2\pi}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | $\mu$ | $\sigma^2$ |

### 6. Математическая статистика

* **Выборка:** Совокупность $n$ случайно выбранных объектов из генеральной совокупности.
* **Точечные оценки параметров:**
* *Выборочное среднее:* $\bar{X} = \frac{1}{n} \sum_{i=1}^{n} X_i$ (несмещенная оценка $M[X]$).
* *Выборочная дисперсия:* $S_0^2 = \frac{1}{n} \sum_{i=1}^{n} (X_i - \bar{X})^2$ (смещенная оценка).
* *Исправленная выборочная дисперсия:* $S^2 = \frac{n}{n-1} S_0^2 = \frac{1}{n-1} \sum_{i=1}^{n} (X_i - \bar{X})^2$ (несмещенная оценка $D[X]$).


* **Методы получения точечных оценок:**
* **Метод моментов:** Теоретические моменты распределения приравниваются к соответствующим выборочным моментам (например, $M[X] = \bar{X}$), и решается система уравнений.
* **Метод максимального правдоподобия (ММП / MLE):** Составляется *функция правдоподобия* $L(\theta) = \prod f(x_i, \theta)$. Оценка $\hat{\theta}$ находится путем максимизации логарифма функции правдоподобия:

$$\frac{d \ln L(\theta)}{d\theta} = 0$$




* **Интервальные оценки и Доверительные интервалы:**
* Интервал $(\theta_1, \theta_2)$, накрывающий истинный параметр $\theta$ с заданной надежностью (доверительной вероятностью) $\gamma = 1 - \alpha$.
* *Доверительный интервал для $M[X]$ нормального распределения при известной $\sigma$:*

$$\left( \bar{X} - z_{1-\alpha/2} \frac{\sigma}{\sqrt{n}}, \; \bar{X} + z_{1-\alpha/2} \frac{\sigma}{\sqrt{n}} \right)$$




* **Проверка статистических гипотез:**
* $H_0$ — нулевая гипотеза, $H_1$ — альтернативная гипотеза.
* *Ошибки:*
* **Ошибка I рода ($\alpha$):** Отклонение истинной гипотезы $H_0$ (уровень значимости).
* **Ошибка II рода ($\beta$):** Принятие ложной гипотезы $H_0$ (мощность критерия $= 1 - \beta$).




* **Критерий согласия Пирсона ($\chi^2$):**
* Используется для проверки гипотезы о соответствии эмпирического распределения теоретическому закону.
* *Статистика критерия:*

$$\chi^2_{набл} = \sum_{i=1}^{k} \frac{(O_i - E_i)^2}{E_i}$$



где $O_i$ — наблюдаемые частоты, $E_i = n \cdot p_i$ — ожидаемые теоретические частоты.
* Если $\chi^2_{набл} > \chi^2_{крит}(\alpha, df)$, то гипотеза $H_0$ отвергается (число степеней свободы $df = k - 1 - r$, где $r$ — число оцененных параметров).
