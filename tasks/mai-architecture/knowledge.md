# Архитектура ЭВМ

> Материал для трека «МАИ», подготовленный по программе вступительного экзамена и конспекту mai.md.

### 1. Центральный процессор (ЦПУ)

* **Арифметико-логическое устройство (АЛУ / ALU):** Выполняет арифметические (сложение, сдвиг) и логические (AND, OR, XOR) операции.
* **Устройство управления (УУ / Control Unit):** Дешифрует команды, формирует последовательность управляющих сигналов для синхронизации всех узлов ЭВМ.
* **Регистровый файл:** Сверхбыстрая память внутри ЦПУ. Основные регистры:
* `PC` (Program Counter) — счетчик команд (указывает адрес следующей инструкции).
* `IR` (Instruction Register) — регистр текущей команды.
* `FLAGS` / `PSW` — регистр флагов состояния (Zero `Z`, Carry `C`, Overflow `V`, Sign `S`).
* `SP` (Stack Pointer) — указатель стека.



---

### 2. Система команд

* **Форматы команд:** Определяют состав инструкции (Код Операции — КОП + Адреса операндов). Бывают 3-адресные, 2-адресные, 1-адресные (аккумуляторные) и 0-адресные (стековые).
* **Способы адресации:**
* *Прямая (Абсолютная):* В команде указан исполнительный адрес операнда в памяти.
* *Косвенная:* В команде указан адрес ячейки памяти, содержащей адрес операнда.
* *Регистровая:* Операнд находится в регистре ЦПУ.
* *Автоинкрементная / Автодекрементная:* Адрес в регистре автоматически увеличивается/уменьшается после/до обращения.
* *Индексная (смещенная):* Исполнительный адрес = Базовый регистр + Смещение.


* **Стадии выполнения инструкции (Instruction Cycle):**
1. *Fetch:* Выборка команды из памяти по адресу из `PC`.
2. *Decode:* Дешифрация КОП и адресов.
3. *Execute:* Выполнение операции в АЛУ или чтение операндов.
4. *Memory / Writeback:* Запись результата в память или регистр, обновление `PC`.


* **Микропрограммирование:** Выполнение каждой машинной команды в виде последовательности элементарных микрокоманд (Hardware vs Microcoded / RISC vs CISC).
* **Прерывания:** Механизм, приостанавливающий выполнение текущей программы для обработки события (Аппаратные, Программные, Исключения/Exceptions).

### 3. Арифметические операции в АЛУ

* **Числа с фиксированной точкой:** Точка строго зафиксирована (обычно после знака или после младшего разряда).
* *Сложение/Вычитание:* Выполняется в дополнительном коде параллельным сумматором.
* *Умножение:* Сводится к серии сдвигов и сложений частичных произведений.
* *Деление:* Вычитание делителя из делимого со сдвигом (алгоритмы с восстановлением и без восстановления остатка).


* **Числа с плавающей точкой (IEEE 754):**
* Формат: $N = (-1)^s \cdot M \cdot 2^{E}$, где $s$ — знак, $M$ — мантисса ($1 \le M < 2$), $E$ — экспонента со сдвигом (Bias).
* *Single Precision (32 бита):* 1 бит знака + 8 бит экспонента (сдвиг 127) + 23 бита мантиссы.
* *Операции:* При сложении/вычитании сначала происходит **выравнивание порядков** (мантисса меньшего числа сдвигается вправо), затем сложение мантисс, затем **нормализация** результата.


* **Переполнение (Overflow):** Возникает, когда результат операции выгружается за пределы разрядной сетки.
* В знаковом сложении переполнение фиксируется по флагу $V = C_{in} \oplus C_{out}$ (перенос в знаковый разряд не равен переносу из него).

### 4. Организация ввода-вывода (I/O)

* **Структуры связей:**
* *Радиальная:* Прямые выделенные линии связи между ЦПУ и каждым внешним устройством.
* *Магистральная (Шинная):* Общая система шин (Шина адреса, Шина данных, Шина управления).
* *Канальная:* Использование специализированных процессоров ввода-вывода (каналов данных), работающих параллельно с ЦПУ.


* **Способы обмена данными:**
1. *Программный ввод-вывод (Polling):* Процессор постоянно опрашивает флаг готовности устройства в цикле (нагрузка на ЦПУ — 100%).
2. *По прерываниям (Interrupt-driven):* Устройство посылает сигнал IRQ, когда готово к обмену.
3. *Прямой доступ к памяти (DMA / ПДП):* Специальный контроллер DMA передает блоки данных напрямую между ВУ и ОЗУ без участия ЦПУ. Процессор освобождается на время трансфера.

### 5. Иерархическая память

Позволяет сбалансировать скорость и стоимость: *Регистры $\rightarrow$ L1/L2/L3 КЭШ $\rightarrow$ ОЗУ (DRAM) $\rightarrow$ Внешняя память (SSD/HDD)*.

```
 Скорость ↑  | [ Регистры ]         | Стоимость ↑
             | [ L1/L2/L3 Кэш ]     |
             | [ ОЗУ (DRAM) ]       |
 Объем ↑     | [ SSD / NVMe ]       |
             | [ HDD / Ленты ]      |

```

* **КЭШ-память:** Быстрая SRAM-память, хранящая копии наиболее часто используемых данных из ОЗУ.
* Основана на принципах **пространственной** (соседние адреса) и **временной** (повторные обращения) локальности.
* *Способы отображения:* Прямое (Direct Mapped), Полностью ассоциативное, Множественно-ассоциативное (N-way Set Associative).
* *Политики записи:* Write-Through (сквозная запись в ОЗУ) и Write-Back (запись в ОЗУ только при вытеснении строки).


* **Виртуальная память:** Абстракция, предоставляющая процессу непрерывное изолированное адресное пространство.
* *Страничная организация:* Память делится на фиксированные *страницы* (Pages, обычно 4 КБ) и *фреймы* (Page Frames) в ОЗУ. Таблица страниц (Page Table) отображает виртуальные адреса в физические.
* *Сегментная организация:* Память делится на логические блоки переменной длины (сегмент кода, данных, стека).


* **Алгоритмы замещения страниц (при промахах / Page Fault):**
* **FIFO:** Вытесняется страница, находящаяся в памяти дольше всех (подвержена аномалии Белади).
* **LRU (Least Recently Used):** Вытесняется страница, к которой не обращались дольше всего.
* **CLOCK (Second Chance):** Приближение к LRU на циклический буфер с битом обращения (Use bit).
* **OPT (OPTIMAL):** Вытесняется страница, которая не потребуется дольше всего в будущем (теоретический идеал).

### 6. Параллелизм и высокопроизводительные системы

* **Классификация Флинна:**
* *SISD:* Одиночный поток команд, одиночный поток данных (классический процессор Фон Неймана).
* *SIMD:* Одиночный поток команд, множественный поток данных (векторные/матричные процессоры, GPU).
* *MISD:* Множественный поток команд, одиночный поток данных (редко, для отказоустойчивых систем).
* *MIMD:* Множественный поток команд, множественный поток данных (многоядерные ЦПУ, кластеры).


* **Аппаратный параллелизм процессоров:**
* *Конвейеризация (Pipelining):* Разбиение выполнения инструкции на этапы (Fetch, Decode, Execute, WB), выполняемые одновременно для разных инструкций.
* *Суперскалярность:* Наличие нескольких параллельных исполнительных конвейеров внутри одного ядра для одновременного запуска нескольких инструкций за один такт.


* **Архитектуры вычислительных систем:**
* *Матричные ЭВМ:* Системы с регулярным массивом процессорных элементов под единым УУ (SIMD).
* *Мейнфреймы:* Высоконадёжные серверные системы с развитой подсистемой ввода-вывода и аппаратно гарантированной отказоустойчивостью.
* *Кластеры:* Группа слабосвязанных компьютеров (узлов), объединенных высокоскоростной сетью (InfiniBand, Ethernet) и работающих как единый ресурс.
